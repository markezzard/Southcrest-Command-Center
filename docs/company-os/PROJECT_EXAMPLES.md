## Pattern confirmed by both examples

These are the core Meridian → Southcrest school delivery pattern:

1. Meridian finds land/site
2. Meridian runs approvals/permitting
3. Project transfers/hands off to Southcrest
4. Southcrest develops/builds
5. Project closes out / turns over
